# ☠ Daily Failure

Aplicativo mobile de frases desmotivacionais diárias com humor ácido e minimalista.

Desenvolvido em React Native + Expo.

## ✨ Funcionalidades

- Frase diária baseada no dia do ano
- Português e inglês
- Compartilhamento nativo
- Interface dark minimalista
- APK Android
- Mais de 300 frases desmotivacionais
- Compartilhamento de frases
- Splash screen personalizada

- Animações suaves

---

## 🚀 Tecnologias

- React Native
- Expo
- TypeScript
- Reanimated
- Expo Router
